# Cyber Watchfolio

A modern, professional portfolio application built with TypeScript for showcasing cybersecurity expertise and projects.

## 🌟 Features

- Clean and responsive design
- Built with modern web technologies
- Professional portfolio presentation
- Deployed on Vercel for optimal performance

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/hackculichi-cloud/cyber-watchfolio.git
cd cyber-watchfolio
```

2. Install dependencies:
```bash
npm install
# or
yarn install
```

3. Start the development server:
```bash
npm run dev
# or
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to see the application.

## 💻 Tech Stack

- **TypeScript** (96.6%) - Type-safe JavaScript
- **CSS** (2.2%) - Styling
- **Other** (1.2%)

## 📦 Build & Deployment

Build for production:
```bash
npm run build
# or
yarn build
```

The application is automatically deployed on [Vercel](https://cyber-watchfolio.vercel.app) with each push to the main branch.

## 📋 Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run lint` - Run linting checks
- `npm run test` - Run tests
