# Proyectos y formación de software

Se incorporan los proyectos que el titular mostró en capturas de su perfil GitHub `ByCulichi`, consultando el README y los repositorios públicos el 15 de octubre de 2026. El catálogo enlaza a código fuente; no se afirma haber probado las aplicaciones externas ni sus demos.

- [Mirror](https://github.com/ByCulichi/Mirror) y [RonnysPage](https://github.com/ByCulichi/RonnysPage): sus `package.json` confirman Next.js, React, TypeScript y Tailwind. Se describe la interfaz sin prometer autenticación o reproducción musical funcional.
- [Calculator-Culichi](https://github.com/ByCulichi/Calculator-Culichi): la versión actual usa React, TypeScript, Vite y Vitest; supera la antigua descripción JavaScript de la captura.
- [Culichi-Metrics](https://github.com/ByCulichi/Culichi-Metrics): README y descripción documentan Python, pandas, XlsxWriter, Excel, formato condicional y gráficas. Se publica como proyecto de automatización, sin copiar atribuciones a empleadores, métricas de impacto o identidades de ejemplo del README.
- [Todo-Culichi](https://github.com/ByCulichi/Todo-Culichi), [WeatherApp-Culichi](https://github.com/ByCulichi/WeatherApp-Culichi), [Journey_blog](https://github.com/ByCulichi/Journey_blog) y [Portfolio-Culichi](https://github.com/ByCulichi/Portfolio-Culichi): ejercicios de interfaz, tareas, clima, blog y portafolio que mostró el titular. Se usan los nombres reales de los repositorios; no los alias antiguos del README.
- Cyber Watchfolio completa las nueve entradas del catálogo. Se ven cuatro al inicio y las demás se despliegan a petición.

Aunque el README afirma «Certified AWS Cloud Practitioner», el titular aclaró que **todavía no aprobó el examen**. En el sitio y los PDF figura como preparación, sin fecha ni insignia de certificación obtenida. Las tecnologías de nube/backend del perfil se describen como aprendizaje. Academlo continúa como estudios inconclusos y los casos de LetsDefend como laboratorios educativos.

Los CV de software, ciberseguridad y atención al cliente se regeneran en ES/EN con `npm run generate:cvs -- --only=software,cybersecurity,customer-service`. El diseño aprobado se conserva, y sus PNG son la primera página real de cada PDF. El generador comprueba que cada documento tenga una página. Los PDF eléctricos originales permanecen intactos.
