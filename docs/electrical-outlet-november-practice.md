# Práctica documentada de cambio de contacto

El titular aportó `New folder (2).zip` el 6 de noviembre de 2026 para publicar otra práctica de contactos. El archivo contiene 43 fotografías: 18 coinciden byte por byte con las fotos de reparación ya publicadas y 16 coinciden con el contacto de octubre. Esas 34 imágenes conservan sus destinos existentes y no se duplican ni se atribuyen a la práctica nueva.

Las nueve imágenes nuevas se conservan byte por byte en `public/images/electrical/outlet-practice-november-2026/`. Se ordenan para presentar el dispositivo original, retiro, caja y conexiones, montaje, placa terminada y fotografías de instrumentos. La portada utiliza la placa blanca terminada. El manifiesto [electrical-outlet-november-evidence.json](electrical-outlet-november-evidence.json) registra cada nombre original, destino, tamaño, dimensiones y SHA-256, además de las coincidencias anteriores.

La ficha `residential-outlet-november-2026` se incorpora a Residencial → Contactos y apagadores como práctica completada con nueve fotografías. No se presenta como empleo o servicio a un cliente ni se atribuye a un curso formal. El nombre de origen incluye el 5 de noviembre, pero no se publica como fecha del trabajo porque no fue confirmada por separado.

La fotografía del multímetro muestra **122.0 V CA**. La fotografía del probador se conserva sin interpretar su código luminoso como una medición independiente de continuidad de tierra. Las descripciones no asignan fase, neutro o tierra por el color del aislamiento, ni afirman procedimientos o valores que no aparecen en el material. La explicación técnica permanece dentro del desplegable existente; la presentación inicial da prioridad a las imágenes y a un resumen breve.
