# Culichi mascot

The owner requested a new fox mascot inspired by the existing local fox logo, related to electricity, electronics, repair, AI and cybersecurity, with a different outfit for each professional area. Artwork was generated with the image generation tool using the existing fox as reference. It is branding artwork, not photographic work evidence.

`src/assets/culichi-mascot-atlas.webp` is a locally stored transparent 3×3 atlas. It was converted to WebP for delivery (about 508 KiB, down from 2.3 MiB PNG). CSS chooses a cell without separate image downloads per costume. `CulichiMascot` shares the artwork across the home hero, profile heroes and header. The header selects the outfit by the actual route. Small bottom viewport masks prevent adjacent atlas rows bleeding into the visible costume.

Row-major order: universal technology fox; SOC; software; electricity; electronics; repair; customer service; AI; fox head emblem. Cyan circuitry, shields, lightning and tools identify the disciplines. The three-wave chest emblem is a stylized reference to Culiacán's rivers, not an official civic logo. No employer or qualification is implied.

`public/favicon.svg` selects the last atlas cell with an SVG viewport. Its embedded image makes it self-contained for favicon restrictions. The original fox asset and original favicon PNG remain available, but are no longer the active logo/favicon.

Future illustration changes should use the image generation tool, preserving the same identity and cell order. No external image service or live AI request is needed when visiting the site.

## Scroll companion and CVs

A second, locally generated 3×2 atlas (`culichi-companion-atlas.webp`) supplies a leaning/waving pose for the six profiles. `MascotInterlude` is inserted twice in each profile: after the specialty cards and before the CV. It participates in normal page flow, so it never floats over content. The second appearance reverses the layout and links to the profile CV. The existing Reveal wrapper animates it into view while respecting reduced motion. No chatbot or data collection is involved.

The PDF generator embeds the original costume atlas offline and selects each profile cell as a small decorative header mark. Text remains selectable and every generated PDF is checked as one page. The electrical original is retained byte for byte; a separate mascot copy is generated by stamping a transparent artwork-only PDF in the free upper-right header area with the installed Python pypdf library. The primary electrical download uses that copy, and a small Original PDF link preserves access to the unmodified document. Extracted text and page count are checked to match the original. Regeneration requires Python with pypdf, Chromium and Poppler; deployed pages require none of these tools.

## General background and typography

The Home hero uses `culichi-home-background.webp`, generated from the original mascot reference as a dark team composition of all six costumes. It is a decorative, local WebP (about 186 KiB), with dark overlays behind text and a stronger uniform overlay on small screens. It does not replace any evidence photographs.

The site uses self-hosted JetBrains Mono regular/bold fonts in public/fonts, with the upstream OFL license included. Body, headings and navigation use the code-style family; the prior external Google Fonts stylesheet was removed. PDFs retain readable body typography and their profile-specific illustration/theme.

The electrical training section includes the owner-confirmed Udemy Electrical Measurements course as in progress. Its ten learning objectives expand on request; a certificate is explicitly pending completion. They are course objectives, not claims of completed qualification.
